# Distributed Task Scheduler - Final Assignment Report

## Executive Summary
This project implements an enterprise-grade Distributed Task Scheduler using Java 21, Spring Boot 3, gRPC, MySQL 8, and React + Vite.

## Architecture Highlights
- Master-Worker pattern using gRPC for high performance communication.
- Automatic worker discovery, heartbeat monitoring, and failover task recovery.
- Java 21 Virtual Threads for concurrent execution.
- Modern React Dashboard with real-time stats and execution log viewer.
